# Constitutional Doctrine Index

## Purpose

This directory contains the constitutional doctrine set for the Relocation App platform.

These documents govern:

- layer sovereignty,
- truth integrity,
- symbolic humility,
- runtime and renderer sovereignty,
- ontology boundaries,
- AI behavior,
- conversational interpretation,
- future excellence,
- and roadmap discipline.

The system is a layered symbolic intelligence platform, not a monolithic astrology AI, recommendation engine, or chatbot with symbolic flavor.

# Core Governance

- Lower layers may inform higher layers.
- Higher layers may never rewrite lower layers.
- Truth flows upward.
- Interpretation never flows downward.
- Rendering visualizes truth; it does not compute or alter truth.
- Symbolic definitions may interpret truth; they may not rewrite truth.
- Optimization suggests; it does not override intention.
- Honest uncertainty is preferable to fabricated certainty.
