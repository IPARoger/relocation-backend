# Micro Decisions Log

Purpose: Capture all project observations, design thoughts, UX ideas, workflow insights, product philosophy notes, implementation observations, and unresolved questions.

This file is the project's capture layer.

Weekly or periodic synthesis may promote recurring patterns into `BIG_PICTURE_DEVELOPMENTS.md`.

Do not promote automatically.

Capture first.

## Rules

1. Append-only.
2. Timestamp every entry with full date and time.
3. Never delete entries.
4. Never rewrite prior entries.
5. Never reorganize entries.
6. Duplicates are allowed.
7. Contradictions are allowed.
8. Capture first, synthesize later.

## Entry Format

```text
====================================================
YYYY-MM-DD HH:MM TZ
#Tag
#Tag
#Tag
====

Entry text...
```
