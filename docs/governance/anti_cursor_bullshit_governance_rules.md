# Anti-Cursor Bullshit Governance Rules

## Status

**CANONICAL** for Phase 3 strategic product architecture.

Operational rules for **AI-assisted development** on this repository. Prevents vibe coding, fake certainty, hidden migrations, renderer panic, and documentation theater.

**Reads with:** `docs/AI_WORKFLOW_GOVERNANCE.md`, `docs/constitutional/implementation_governance_and_ai_workflow_protocol.md`, `docs/process/ai_drift_audit_framework.md`, `docs/review_contracts_and_governance.md`, `validation/narratives/phase3_26_accountability_failure_audit.md` §Anti-Bullshit Rules.

---

## Purpose

Cursor and other AI agents are **accelerators**, not authorities.

This project assumes **low trust in AI outputs until proven**.

Every agent claim requires:

1. **scope** — what is in/out,
2. **evidence** — what was read, run, measured,
3. **rollback path** — how to revert,
4. **test method** — how to verify,
5. **exact changed files** — no hand-waving.

## Forbidden agent behaviors

### Truth and evidence

- claiming code works without running relevant smoke/tests,
- screenshots as proof without mechanism,
- “emergent” without causal code path,
- hardcoded booleans as validation,
- scripted timing described as solver behavior,
- retiring metrics without deconstruction (see Phase 3.33 pattern),
- grep-green reports that don't match runtime.

### Architecture

- Layer 2 altering Layer 1 truth,
- renderer computing symbolic meaning,
- sandbox hydration becoming silent production path,
- local JSON / localStorage becoming product DB without explicit decision,
- seam surgery on canonical geometry for cosmetics,
- auto-promoting canonical renderer,
- mixing debug of math + renderer + UI + AI in one diff.

### Documentation

- “no docs needed” without specific justification,
- promoting archaeology/raw continuity to doctrine without cross-check,
- creating docs user didn't ask for (scope creep),
- generic governance platitudes without file paths,
- restating intent without enforcement hooks.

### Product / UX

- dashboard chrome that hides map evidence,
- Photoshop layer panel on mobile,
- deterministic “best city” defaults,
- oracle copy, destiny theater, cosmic hype,
- tutorial tours and coach mark spam.

## Renderer freeze checklist

Do **not** reopen unless map sandbox proves:

- centerline drift,
- broken side-local scaling,
- label/readability collapse,
- pane-order impossibility.

**Frozen:**

- transported-material doctrine,
- side-local proportional scaling,
- orthogonal slice doctrine,
- embedded ridge doctrine.

**Flexible:**

- palette, overlap compositing, child colors, material finish, layer UX.

Aesthetic dissatisfaction alone is **not** evidence.

From `docs/process/ai_drift_audit_framework.md` — flag High severity before ship:

- tradeoff erasure,

## Implementation agent discipline

| Do | Don't |
|----|-------|
| diff-based minimal patches | drive-by refactors |
| feature flags for risky visuals | silent behavior change |
| scoped git adds | stage whole workspace |
| say UNPROVEN when uncertain | fake coherence |
| validation sandboxes before production | edit `map_CURRENT.html` for experiments |
| preserve rollback commits | force push main |

**Python/JS math edits:** confirm module loaded by running server matches edited file.

## Pre-implementation gate (animation / emergence)

Before any animation work (`phase3_26` gate):

- causal state model documented,
- forbidden shortcuts listed,
- acceptance tests written,
- verification commands defined,
- proof final state is not time-scripted,
- no decorative sky claimed as active population.

**Rain/virga/emergence = rejected for MVP product** unless gate passed and user explicitly approves.
