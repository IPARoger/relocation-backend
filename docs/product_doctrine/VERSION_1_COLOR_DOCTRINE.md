# Version 1 Color Doctrine

## Status

Baseline doctrine for beta experimentation.

This is not final brand law. It is the first stable color system to test across the real app.

## Core Principle

The product may offer multiple color profiles, but it must not feel like multiple unrelated products.

One shared core travels through all themes:

**Core Ink / Graphite**  
`#252A2E`

This may be tested against the existing chart-wheel charcoal. If the existing charcoal performs better inside the wheel, preserve it for wheel geometry while using Core Ink for the broader product UI.

The goal is not obvious color decoration. The goal is subtle warmth, depth, and orientation that users feel before they consciously notice it.

## Universal Spine

Core Ink should be tested for:

- logo
- primary text
- navigation
- table text
- comparison text
- map drawer text
- UI borders where appropriate
- chart wheel lines only if it does not damage the current wheel dignity

The chart may keep a specialized charcoal if it proves better.

## Texture Doctrine

Use micro-texture only.

The intent is not fake paper, fake linen, fake papyrus, or skeuomorphic material imitation.

The intent is to prevent dead printer-paper flatness and give surfaces enough dimensionality to feel alive.

Texture should be felt after five minutes, not noticed after five seconds.

## Four Beta Color Profiles

Users may eventually choose among four seasonal color profiles. This helps beta testing avoid false perfectionism and allows different users to select a mood that fits their use case.

The four profiles are:

1. Spring — Possibility
2. Summer — Expansion
3. Autumn — Study
4. Winter — Threshold

These are atmosphere palettes, not planet/data palettes.

## Page-Weighted Usage

The app may allow user-selected seasonal themes, but pages still have native emotional weighting.

### Map

- 70% Spring
- 20% Summer
- 10% Winter

Purpose: possibility, movement, discovery.

### Profile

- 60% Winter
- 30% Spring
- 10% Autumn

Purpose: understanding, factual dignity, fresh self-recognition.

### Comparison

- 70% Autumn
- 20% Winter
- 10% Spring

Purpose: discernment, confidence, decision support.

### Transit Lab

- 50% Summer
- 30% Winter
- 20% Spring

Purpose: movement, timing, experimentation, precision.

## Data Palette Separation

These profiles do not solve the full planet/data visualization system by themselves.

The app still needs:

- 12 distinct planet/map overlay colors
- child overlap colors
- aspect-family colors
- NOT/exclusion charcoal/redacted variants
- chart-wheel line and glyph color rules

The atmosphere palette and data palette must remain related but separate.

## Beta Strategy

Implement the four profiles as selectable settings.

Use real app screens to test them:

- Genie / Map
- Profile / Wheel
- Comparison
- Settings

Do not rely on abstract swatches.

The palette is successful only if it survives contact with real UI, real tables, real chart wheels, and real map overlays.
