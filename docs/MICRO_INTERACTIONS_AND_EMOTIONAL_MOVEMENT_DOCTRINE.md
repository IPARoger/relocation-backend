# Constitutional Anchor

**Reveal Structure. Preserve Judgment.**

Motion exists to reveal truth, not manufacture excitement.
Emotion exists to support discovery, not manipulate behavior.

The application is an instrument, not a casino, game, social network, or productivity dopamine machine.

Users should feel:

- curious
- oriented
- capable
- contemplative
- respected

Users should not feel:

- rushed
- pressured
- optimized
- gamified
- emotionally steered

---

# Emotional Movement Doctrine

The desired emotional arc is:

### 1. Orientation

"What am I looking at?"

The interface provides calm certainty.

No spectacle.

No mystery-box reveal.

No dramatic onboarding.

---

### 2. Exploration

"Interesting. I wonder what is over there."

The map becomes inviting.

Curiosity emerges naturally from visible structure.

Not from rewards.

Not from alerts.

Not from streaks.

---

### 3. Discovery

"Oh. That's where it happens."

Discovery should come from finding meaningful geography.

The emotional reward comes from recognition.

Not animation.

Not sound effects.

Not celebration.

---

### 4. Comparison

"Huh. These places are different."

The interface helps users think.

It does not tell them what to think.

---

### 5. Reflection

"This might matter."

The strongest emotional moment should occur inside the user.

Not inside the UI.

---

# Motion Doctrine

Motion must answer one of four questions:

### Where?
Drawer opens.
Map flies.
Viewport changes.

### What Changed?
Overlay appears.
Layer toggles.
Search completes.

### What Is Important?
Subtle emphasis.
No shouting.

### What Is Connected?
Hover relationships.
Selection relationships.
Comparison relationships.

If motion cannot answer one of these questions, remove it.

---

# Rain / Virga Status

Rain and Virga remain future research.

They are not active product requirements.

If revisited:

- truth first
- pacing second
- beauty third

Never fake computation.

Never animate meaningless activity.

# Final Test

Before adopting any interaction, animation, layout, or visual pattern:

1. Does it reveal structure?
2. Does it preserve judgment?
3. Does it improve orientation?
4. Does it improve comparison?
5. Would it still be valuable with all animation removed?
6. Is the emotional reward inside the user rather than the UI?

If not, reject it.
