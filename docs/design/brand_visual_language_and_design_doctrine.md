# Brand, Visual Language, and Design Doctrine

## Status

**CANONICAL** for Phase 3 strategic product architecture.

Consolidates **brand foundations**, **visual epistemology**, and **restrained premium language** for the professional non-AI MVP. Not a logo guide. Not marketing.

**Reads with:** `docs/brand_and_experience_foundations.md`, `docs/visual_semantic_style_guide.md`, `docs/overlay_and_aura_visual_strategy.md`, `docs/ux_principles_and_emotional_tone.md`, `docs/constitutional/symbolic_language_style_guide.md`.

---

## Purpose

Ensure the product reads as:

- contemplative symbolic geographic instrument,
- calm, restrained, inspectable, premium, trustworthy, professional.

Ensure it does **not** read as:

- generic astrology SaaS,
- mystical rainbow dashboard,
- AI oracle theater,
- cosmic clipart,
- neon toy map.

---

## Brand posture (non-marketing)

| Axis | Stance |
|------|--------|
| **Category** | Relocation astrology exploration — not generic astrocartography clone |
| **Metaphor** | Instrument, not dashboard |
| **Emotion** | Contemplative long-session comfort |
| **Trust** | Inspectable precision over visual confidence |
| **Fantasy** | Allowed in user meaning-making; forbidden in fake certainty |
| **AI** | Later layer; chrome stays calm without it |

**Tagline discipline:** no public tagline in this doc. Positioning language (“decision intelligence”) requires ethics review before UI copy.

---

## Visual epistemology (truth hierarchy)

| Surface | Contract |
|---------|----------|
| **Popup / point inspect** | Canonical truth *here* |
| **Overlays** | Exploratory *where* fields |
| **Account / chart pages** | Full scientific record |
| **Export** | Must declare tier (exploration vs authoritative) |

**Beauty from truthful systems** — decorative fog, fake glow, blur that moves membership = rejected.

---

## Color language

### Principles

- grayscale-friendly structure,
- semantic families, not rainbow planet defaults,
- overlap readability beats palette purity,
- strong saturation reserved for **meaning**, not decoration,
- colorblind-safe planning required before ship.

### Layer families (target)

| Family | Role | Notes |
|--------|------|-------|
| House conditions | categorical regions | distinct hues; moderate fill opacity |
| Angle in sign | categorical | separate from house — not purple mud |
| Aspect to angle | centerline + material strip | not neon teal toy |
| Overlap child colors | deliberate blends | replace accidental alpha mud |
| NOT / exclusion | desaturating veil | off-limits, not punitive red |

**Current A/B/C yellow/blue/rose + purple + teal = proof-of-concept only** (`docs/overlay_and_aura_visual_strategy.md` §J). Engineering validation ≠ product palette.

### Rejected aesthetics

- default rainbow astrology UI,
- neon map accents,
- generic SaaS purple-teal dashboards,
- astrology emoji in chrome,
- fake premium fog/glow,
- Gaussian mush masquerading as truth,
- ornamental gradient without semantic job.

---

## Typography and spacing

- calm, legible, instrument-grade,
- popups dense but not spreadsheet-on-map,
- account pages may be denser,
- generous whitespace on map chrome,
- no marketing banner weight in controls.

**Premium = quiet confidence** — fewer elements, each earning pixels.

---

## Cusp vs aura (do not conflate)

| System | Scale | Reads as |
|--------|-------|----------|
| **House cusp transition** | ~2° display gradient | categorical boundary softness — **not** uncertainty |
| **Aspect aura / material strip** | orb bands (~4–8° tunable) | angular intensification toward exact line |

Separate ramps, colors, and copy. One muddy metaphor breaks trust.

**Renderer note:** beta **transported-material strip** implements aspect intensification; aura occupancy-band doctrine describes truth sampling — both subordinate to popup + centerline.

---

## NOT / exclusion visual language

- soft veil: desaturate, mute, low-contrast scrim,
- geography stays readable,
- no inverse glow of entire habitable map,
- no alarm red danger language,
- communicates **deprioritize**, not **punish**.

---

## Overlap semantics

- overlap zones are **discovery objects**, not clutter to hide,
- optional hotspot highlight: off by default,
- no paternalistic “best/winner/top” unless user declares optimization constraints,
- prefer “notable overlap,” “candidate zone,” “high-concentration.”

---

## Map readability (hard constraint)

Sacred under overlays:

- city labels,
- coastlines,
- political boundaries,
- clickable candidate places.

If encoding fails readability, encoding fails — regardless of beauty.

---

## Motion and animation

### Allowed (sparingly)

- drawer collapse/restore,
- overlay staging tied to **computed truth availability** (future, gated),
- subtle hover/focus states.

### Forbidden / deferred

- rain / virga product animation,
- speculative emergence theater,
- game-like map chrome,
- timing theater masquerading as solver behavior,
- loading animations that imply precision not yet computed.

**Rule:** motion never substitutes for truth; never hides incomplete computation as finished.

---

## Symbolic language (UI copy)

Follow `docs/constitutional/symbolic_language_style_guide.md`:

- prefer “may,” “one possible expression,” “this pattern often relates to,”
- reject prophetic, destiny, cosmic guarantee language,
- professional tone: archetypal literacy without mystique performance.

**UI chrome stays calm;** interpretive intensity may live in content layers later — not in neon buttons.

---

## Style presets (future)

May change:

- palette families,
- material finish,
- contrast curves,
- emotional temperature of fills.

Must **not** change:

- transport math,
- side-local normalization,
- popup truth,
- implied astrological certainty,
- Layer 1 membership.

---

## Account / intake as tone anchor

Birth data intake, client dashboard, and settings establish **premium calm** before map drawer inherits the same tokens.

These screens are not boring utility — they are the user's first trust handshake.

---

## Design system minimum (before drawer ship)

1. spacing scale,
2. type scale (2–3 weights max in map chrome),
3. semantic color tokens (layer families + NOT + overlap children),
4. elevation/shadow restraint (prefer flat + border),
5. icon set — literal, not mystical,
6. focus/disabled/error patterns.
