# Micro Decision Log v1 — 2026-06-02

Purpose: Track specific product, UX, naming, and workflow decisions that supersede older ambiguity.

Rule: Newer dated entries win over older conflicting language unless explicitly marked exploratory.

## Decisions

### 0001 — Favorite
Favorite = saved place.
A Favorite preserves a location/coordinate/city that matters for one chart/person.

### 0002 — Saved Search
Saved Search = saved inquiry.
It preserves search conditions, chart context, settings snapshot, viewport/context, and replay metadata.

### 0003 — Comparison Default Layout
Comparison default = horizontal layout.

### 0004 — Comparison Alternate Layout
Users may later switch Comparison to vertical layout in preferences/settings.

### 0005 — Comparison Count
Comparison supports 2–5 places at once.

### 0006 — Comparison Notes
Comparison notes live in the second-to-last column.

### 0007 — Notes Format
Notes are rich text popup/box fields.

### 0008 — Voice Notes
Voice note / microphone support is allowed as a future notes input affordance.

### 0009 — Comparison Content
Comparison compares relocated chart facts for selected places: wheels, planet-in-house tables, aspect-to-angle tables, angle-in-sign tables, and human notes.

### 0010 — Comparison Forbidden Content
Comparison must not contain scores, rankings, best-city verdicts, opportunities panels, climate scoring, city benefit cards, or AI recommendations as primary content.

### 0011 — Profile Page
Profile Page = study base for one chart/person.
It is not a dashboard, CRM, account page, city-ranking page, or map search surface.

### 0012 — Account vs Profile
Dave Goodman = logged-in account/session identity.
Anna Rivera = working profile/chart subject in mockups.
Do not use Dave as both owner and subject in the same mockup.

### 0013 — UI Language
Do not print planning phrases as UI copy:
- Who You Are
- Where You Are
- Working Context
- Preset
- Account Owner

### 0014 — Current Location
Current Location is first-class.
It is the person’s current lived place/chart context, not minor metadata and not an account location.

### 0015 — Genie
Genie builds and modifies map searches only.
No profile editing, CRM cards, favorites archive, or account management inside Genie.

### 0016 — Search Flow
Build Search → Search Map → Explore Results → Modify Search → Explore Results.

### 0017 — After Search Map
After Search Map, Genie retracts and map/overlays become primary.
Search/chrome/back/forward/pin controls recede visually; they do not become louder.

### 0018 — Save Search Affordance
Save Search can exist while building/modifying.
After Search Map, it may transform/migrate into a disk glyph at the map edge.

### 0019 — NOT vs Mute/Solo
NOT is search logic.
Mute/Solo are layer-viewing tools.

### 0020 — City Labels
City labels should be clickable where possible.
Avoid tiny dot-only UX.

### 0021 — City Density
City density should be based on screen-space/map-square-inch readability, not raw population alone.
Borrow Google Maps-style prioritization.

### 0022 — Profile Page V2 Process
Design Profile Page V2 one step at a time:
information architecture → wireframe hierarchy → visual mockup → style extraction.
