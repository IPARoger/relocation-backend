# VISUAL REFERENCE BOARD

**Purpose:** Real visual references for the relocation astrology instrument.
**Use:** Pull each search phrase into image search and study the look/feel. This is a mood board, not a spec.
**Feel test:** What this should feel like sitting in a café in Ubud, Porto, Chiang Mai, Lisbon, Medellín, Austin, or Bali for two hours.

---

## MAP

**Apple Maps**
- Search: `Apple Maps macOS muted base map labels`
- Steal: The suppressed, calm base map where labels and roads fade in and out gracefully by zoom.
- Reject: The turn-by-turn navigation urgency and consumer routing gloss.

**Windy.com**
- Search: `Windy.com wind map layered overlay`
- Steal: Multiple atmospheric fields layered legibly under one opacity discipline.
- Reject: The storm/weather urgency and emergency color spikes.

**National Geographic Atlas**
- Search: `National Geographic atlas map plate typography`
- Steal: Editorial cartography with disciplined, hierarchical label placement.
- Reject: The nostalgic print-imitation and decorative borders.

**FlightRadar24**
- Search: `FlightRadar24 live air traffic map`
- Steal: Thousands of objects staying legible, with hover-to-inspect a single one.
- Reject: The icon overload and aviation-cockpit busyness.

**OpenRailwayMap**
- Search: `OpenRailwayMap infrastructure line map`
- Steal: Line discipline and infrastructure hierarchy on a quiet base.
- Reject: The raw OSM clutter and unfiltered density.

**earth.nullschool.net**
- Search: `earth nullschool global wind visualization`
- Steal: A single continuous, mesmerizing flow field over a dark globe.
- Reject: The hypnotic spectacle that would override factual inspection.

**Google Earth**
- Search: `Google Earth fly to camera globe`
- Steal: Continuous "fly-to" camera that teaches the path between two places.
- Reject: The cinematic swoop and awe-as-spectacle.

**Swisstopo (Swiss Federal Topographic maps)**
- Search: `Swisstopo Swiss national map relief shading`
- Steal: Precise relief shading and restrained color that reads as authoritative.
- Reject: The extreme topographic density unsuited to a sparse instrument.

**Ordnance Survey maps**
- Search: `Ordnance Survey Explorer map detail`
- Steal: Trust through consistent, legible symbol systems.
- Reject: The hiking-map clutter and symbol overload.

**NASA Black Marble (Earth at Night)**
- Search: `NASA Black Marble Earth at night lights`
- Steal: Human geography emerging as gentle points of light on a dark Earth.
- Reject: The satellite-photo realism that competes with abstract overlays.

**Stamen Toner / Mapbox Light**
- Search: `Mapbox Light style minimal base map`
- Steal: An almost-invisible monochrome base that lets overlays own the color.

**The Times Comprehensive Atlas of the World**
- Search: `Times Comprehensive Atlas world map spread`
- Steal: Premium, weighty cartographic authority and label craft.
- Reject: The reference-book density that overwhelms a screen.

**MarineTraffic**
- Search: `MarineTraffic live ship map`

- Reject: The dense vessel-icon swarm near ports.

**Ventusky**
- Search: `Ventusky weather map smooth gradient`

- Reject: The weather-app saturation and animated drama.
