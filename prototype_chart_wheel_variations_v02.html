Chart wheel — gravitas pass & color variations

Heavier hierarchy to fix the flimsiness, plus saturation tests so we can pick a clear-but-tasteful point.

1 · Gravitas pass (balanced palette)

What changed vs v01: outer double-ring band for weight; the outer ring is now ~2.6px ink. Sign boundaries, house spokes, and ticks are pushed further apart in value so the greyscale hierarchy is visible, not uniformly faint.

Lines use rounded caps + geometricPrecision and higher minimum weights, which removes the per-pixel "wobble." ASC/MC axes are the heaviest non-color elements — the orientation anchors.

Color is still spent only on aspect lines.
