Widget  TTF  ReadMe
_________________

Production Information:
This is the first release of the Widget Astrological font.
It is the 1st font in the Astrological Font Series. 
This font was created on a PC running Win98 with UK keyboard layout.
And Designed using ScanFont v3.1.3 & FontLab v3.

About the Typeface:
Widget was created due to the distinct lack of other astrological alternatives.
Designed in a semi handwritten / weathered style initially for my own personal use.

More Typefaces:
Future typfaces releases will include Astroids, TransNeptunians, and minor aspects.
