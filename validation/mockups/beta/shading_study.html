Shading & Divider Study

Same table, eight treatments. The question: how little shading / color do we need for rows to read cleanly — with and without dividing lines? The chart pages currently use texture zebra, no lines (treatment C).

Texture = diagonal hatch only · Color = flat fill · Lines = hairline row divider

Recommendation lane: C / D keep the page warm and “alive” without introducing emotional color bias. F–H show how little color reads as a row band — useful if we later want a faint per-table tint (e.g. teal = PiH, gold/brick = A2A) to subconsciously teach the user what’s what. Pick one column treatment and one optional per-table hue, and it locks as doctrine across all pages.
